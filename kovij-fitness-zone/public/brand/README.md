# Kovij Fitness Zone brand kit

The logo: a slanted **K** on a red tile with the top-right corner cut (the same cut as the website's buttons), next to **KOVIJ** in Lexend Black (slanted) and **FITNESS ZONE** in Lexend Bold, spaced to the same width.

See `kovij-brand-sheet.png` for everything on one page.

## Which file to use

| Where | File |
|---|---|
| Website, documents, light backgrounds | `kovij-logo-horizontal.svg` (or `png/kovij-logo-horizontal-*.png`) |
| Dark backgrounds, photos with a dark area | `kovij-logo-horizontal-on-dark.svg` |
| Square spaces: posters, signboard, ID card | `kovij-logo-stacked.svg` / `-on-dark.svg` |
| App icon, favicon, stickers, small spaces | `kovij-mark.svg` (`png/kovij-mark-1024.png` … `-64.png`) |
| Instagram / Facebook / WhatsApp / Google profile picture | `social/kovij-profile-1080.png` (or the red version) |
| Facebook cover, link previews (Open Graph) | `social/kovij-cover-1200x630.png` |
| One colour only: embroidery, stamps, engraving, fax | `kovij-logo-horizontal-mono-black.svg` / `-mono-white.svg`, `kovij-mark-cutout-*.svg` |
| Matching the staff and member app | `kovij-logo-horizontal-orange-on-dark.svg`, `kovij-mark-orange.svg` |

The SVG files are the masters: every letter is a vector outline, so they print sharp at any size and need no fonts. Open them in Figma, Illustrator, Inkscape or Canva. The PNGs have transparent backgrounds.

## Colours

| Name | Hex | Use |
|---|---|---|
| Kovij Red | `#D32F2F` | Logo, website, buttons |
| Ink | `#121212` | Text, dark backgrounds |
| White | `#FFFFFF` | Text on dark, light backgrounds |
| App Orange | `#FF7A1A` | Staff and member app |

## Type

Headings: Lexend Black, slanted. Body text: Poppins on the website, Manrope in the apps.

## Rules

- Clear space around the logo: at least the height of the tile's cut corner.
- Smallest size: the mark at 16 px; the full logo at 120 px wide.
- Don't stretch, rotate, recolour outside the palette, add shadows or outlines, or set the full-colour logo on a busy photo. Use a one-colour version there.
